# 示例小说

本目录提供四本**公版古典小说** TXT，便于克隆仓库后立刻试用入库与问答：

| 文件 | 说明 |
|------|------|
| `novels/红楼梦.txt` | 《红楼梦》 |
| `novels/三国演义.txt` | 《三国演义》 |
| `novels/水浒传.txt` | 《水浒传》 |
| `novels/西游记.txt` | 《西游记》 |

## 入库方式

**前端**：启动后在左侧点击「导入 TXT 小说」，选择上述文件之一。

**命令行**：

```bash
python scripts/ingest_book.py samples/novels/西游记.txt
```

首次向量化可能需要数分钟（视网速与章节量而定）。

## 当前支持的入库格式

| 格式 | 状态 |
|------|------|
| `.txt` 纯文本 | **已支持**（唯一入库格式） |
| PDF / Word / EPUB | **未支持** |
| 图片 / OCR 扫描件 | **未支持** |

知识库入库链路目前只接受 TXT：按「第 N 章 / 第 N 回」等标题切章后写入向量库与 BM25。  
请先将其它格式自行转为 UTF-8 / GBK 可读的 `.txt` 再导入。
